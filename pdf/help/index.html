Solander PDF Help

Quiet Signals Lab  ·  For Solander PDF 1.0  ·  Last updated: 8 October 2026

Solander PDF finds what identifies people in a PDF, a scan or an image, shows you every box before it is drawn, writes a new file with the boxes burned in, and reads that file back to check it. Everything happens on your Mac. This page says how each part works; the app itself says less, on purpose.

Opening a document

Choose File › Open (⌘O), drop a file on the window, or open it from the Finder. Solander reads the document page by page: the window fills with the pages as they are read, and you can stop at any time. Reading a long scan takes minutes, because every page is recognised and every detector runs on this Mac.

One document at a time is free, with every detector, the whole workbench, the export and the check. A licence adds batches, evidence files, reason codes, saved profiles, watch folders and the command-line tool.

The window

  • The sidebar lists the pages, with what each still needs: how many findings are to review, how many are redacted, and whether you have viewed it. Filter it to the pages to review or the pages not yet viewed. Hide it with ⌃⌘S.
  • The page is the middle, at the size the export will be. Four layouts (View menu, ⌘1 to ⌘4), Actual Size (⌘0), Zoom to Fit (⌘9), Zoom to Width (⌥⌘9), pinch to zoom, Go to Page (⌥⌘G), and Back and Forward after a jump (⌘[ and ⌘]).
  • The workbench on the right covers the whole document, in five tabs. Hide it with ⌃⌘I.
  • The toolbar holds the tools: Select (V), Mark Text (T), Mark Area (M) and Mark Pages (⇧⌘P). Customise it from the View menu.

Marks on the page

The page shows the output. A filled black box is a redaction that will be burned into the file. An outlined box is a finding you have not decided about: it will not be redacted unless you say so. A dashed outline is a suggestion from the language model rather than a pattern match. A yellow dashed outline is text the recogniser could not read, which no detector examined. The box under the pointer darkens and names its value, and the selected box carries a blue ring with handles to move or resize it.

Decide a finding with the Redact menu or its keys: Redact (A), Leave Visible (R), Change Decision (Space), Redact Every Occurrence (E), Delete Box (⌫) for a box you drew. The arrow keys walk the findings, Tab walks the ones still to decide. Right-click any box for the same commands. View › Show Redactions as Outlines (⌥⌘R) lets you read what is under a box; the export is always filled.

The single-letter keys can be turned off in Settings › Review, for voice control or a switch device.

The workbench

  • Overview says what is left before you export: findings to decide, pages not viewed, lines that could not be read, and what hidden content the file carries. None of these stops an export; the report records each of them.
  • Values lists every value in the document, grouped by category, with every place it appears. Decide a value at a time with Redact All or Leave All. Names that are probably one person are suggested for merging, never merged for you; a fragment read on its own is offered for folding into the value it belongs to. Split a merged value by spelling from its context menu.
  • Find (⌘F) searches the words recognised on the page and the file's own text, ignoring case and accents. Every match is listed before anything is covered, and each can be unticked. Patterns find what you do not know the value of: numbers of six digits or more, dates, e-mail addresses, or a regular expression of your own. Always Redact adds the term to this document's rules.
  • Rules decide a whole category (Ask, Redact or Leave) and hold terms to always or never redact. A rule decides only what nobody has decided by hand, and never changes a decision you made; removing a rule puts its findings back as they were found. The report says which boxes a rule decided. Rules for this document are free; saving them into a profile is part of a licence.
  • File lists what the file contains besides its pages, which is left out of the export; the lines that could not be read; the profile the document was read under; and, after an export, what the checks said and where the files went.

Exporting

Export (⇧⌘E) opens one sheet. Output is the folder: documents go into “Solander Exports” inside it, and originals are never changed. If you have not chosen a folder, Export asks for it. Pages sets a size limit for the recipient's system (a document over the limit is written as volumes, each under it and each checked), the page image format, an accessible tagged PDF for screen readers, and, when a court requires it, a searchable text layer read from the redacted pages. Evidence is what goes to the recipient beside the documents, with a checksums file anyone can verify with shasum. Sign-off records who reviewed and who approved, and can sign the report with a certificate from your Keychain. What stays with you is written beside the exports folder, never inside it.

After an export, the File tab shows what the check found and where the files are. If a check does not pass, nothing is written; you can adjust the boxes and export again, or keep the output anyway, which goes into a “needs attention” folder and is recorded in the report.

What the check covers

A passing check means no readable text remains inside the regions you redacted, and that the written file contains only page images: no metadata, annotations, attachments, scripts or text from the original. It does not mean everything sensitive was found. Detection can miss things, especially names, addresses and text in non-Latin scripts, so you review every document. Text the recogniser could not read is listed and marked on the page, because no detector examined it. Solander does not describe a document as anonymous, compliant or safe, and it is not legal advice.

The report says how many pages you viewed. A page counts as viewed once at least half of it, or half the window when it is zoomed larger than the window, has been on screen for one second.

Evidence

With a licence, each export can be accompanied by a signed report in JSON and PDF (what was redacted and why, what was checked, what the original contained, and a hash of the exported file), a redaction log in CSV or PDF with one row per box and its reason code, a privilege log for pages withheld in full, a load file for review software, and a Woo inventory for Dutch disclosures. None of them contains text from the document.

Reason codes are the legal ground for a redaction, drawn inside the box and recorded in the log. Every set Solander ships is a template that no practitioner has reviewed in its jurisdiction: check its grounds against your own authority before a disclosure goes out, or install a set someone qualified has written. A set is a JSON file of codes with a label per language; codes use letters, digits and ().-_ only, because they are drawn inside the box and read back by the check.

Checking a document someone sent you

File › Check a Redacted Document (⌘K) is free and needs nothing open. Solander re-reads the file itself. With the report that came with it, it re-checks every redaction the report records; without a report, it checks any PDF for text left under boxes and content kept in the file. If a certificate signature came with the report, it says whether the report is unchanged and whether this Mac trusts the certificate.

Profiles, watch folders and the command line

A profile decides the resolution pages are read at, what the detectors look for, the box widths, the output naming and the production stamp, so changing it reads the document again. A profile may also record the input hash (which ties the report to the original, and lets anyone holding both confirm a guess about the unredacted document), pseudonymise (draw (PERSON-1) in the box, the same label for the same value in every document), add a searchable text layer, and allow unattended use.

A watch folder reads anything dropped into it, so a document is ready to review by the time you open it. Folders are watched while Solander is running; what arrives in the meantime is picked up next time it opens. With a profile marked for unattended use, a watch folder or the solander command-line tool can redact with nobody looking; every output made this way records that nobody did, and anything that fails its check goes to the “needs attention” folder instead.

Settings

  • General. A review is saved as you work, so it survives quitting; the record holds no text from the document, only which boxes you decided and where, and it is deleted after 30 days. Recent documents are off by default, because a list of them says which documents this Mac has opened.
  • Review. The page layout, which findings are shown, redactions as outlines, and the single-key shortcuts.
  • Text Size is in the View menu: three steps, for every window.
  • Licence. Your licence file is signed, and the signature is checked on this Mac against a key built into the app. A separate helper process confirms the purchase about once a week; it sends the licence ID and nothing about your documents, and if it cannot reach us the licensed features keep working for 30 days. A Mac that must never connect can be activated offline with a code: a first activation lasts 15 days and a renewal 90.
  • Updates. Checks can be turned off; licence confirmation is separate and cannot.

Privacy

The app that opens your documents has no network access at all: it is sandboxed without the network entitlement, which you can verify yourself with codesign -d --entitlements - "/Applications/Solander PDF.app". The privacy notice lists exactly what the two helper processes send.
