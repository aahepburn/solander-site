Features

  1. Stays on your Mac

    Solander works the way desktop software always did: your files stay on your Mac, and everything happens there, offline. The text recognition and detection are modern, and they run on the Mac itself. Nothing is uploaded, and there is no account. How to check this yourself

  2. Checks every file before you send it

    A black box drawn over text in a PDF can often be moved, or the text under it copied out. Solander PDF writes a new file, reads it again, and shows you any text that is still readable under a redaction. It also marks any text it couldn’t read, so you know which parts no detector examined. Solander Desk checks each exported file for anything you chose to remove.

  3. Keeps an audit trail

    Give each redaction a reason code, such as a US FOIA exemption or a set you install for your own jurisdiction, and the code is printed in the box. Solander PDF keeps a redaction log and produces a signed report in PDF and JSON that you hand over with the documents. Whoever receives them can check the documents against the report with the free app.

  4. Handles a whole production

    Redact a folder of documents at once, with each name redacted the same way in all of them. Add Bates numbers that run on across the set, a privilege log for documents withheld in full, and a load file for review software. Turn on searchable text for courts that require it.

FAQ

Does it find everything that should be redacted?

No. Solander PDF finds common personal details such as names, email addresses, phone numbers and ID numbers, but it misses some, especially names, addresses and text in non-Latin scripts. You review every page and can add redactions yourself. The check after export confirms that what you redacted can no longer be read; whether anything else should have been redacted is your decision. Text replaced with placeholders in Solander Desk is still personal data under the GDPR.

Is the redacted PDF searchable?

By default, no. Solander PDF saves each page as an image, so its text can’t be selected or searched. With a licence you can turn on searchable output: Solander PDF reads the redacted pages again and adds a hidden text layer, which is checked along with the pages. The litigation preset turns it on. The text layer supports Western European characters only.

Does anything go online?

Two small helper processes connect to the internet: one checks for updates, and one confirms your licence about once a week. Neither receives your documents or anything found in them. The privacy notice lists exactly what they send.

Can I use it without an internet connection?

Yes. Everything Solander does with your documents happens offline. If the licence check can’t connect, the paid features keep working for 30 days. A Mac that is never online can be activated with a code instead, which you enter on a web page from your phone or another computer.

Which app do I need?

Solander PDF for PDFs, scans and images, where the result is a PDF. Solander Desk for Word, Excel and LibreOffice files that need to stay editable. The Suite covers both.

I already own one app. Do I pay full price for the Suite?

No. You pay the difference, and your new Suite licence works in both apps. You will need the licence ID from your licence email and the address it was sent to.

Is there a subscription?

No. You pay once, and the licence includes future versions.

Can I get a refund?

Yes, within 14 days, with no reason needed. The licence is then deactivated; free mode keeps working, and the files you have already produced are untouched. See Refunds.

Which Macs does it run on?

macOS 14 Sonoma or later, on Apple Silicon and Intel Macs. The apps are signed and notarised by Apple.
