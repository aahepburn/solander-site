Solander Desk Help

Quiet Signals Lab  ·  For Solander Desk 1.0  ·  Last updated: 8 October 2026

Solander Desk shows what is hidden in a Word, Excel or LibreOffice file, removes what you choose, and checks its own work. The file stays editable and the original is never changed. It can also replace names with placeholders before you paste a document into an AI tool, and put the names back in the answer. Everything happens on your Mac.

Opening files

Choose File › Open (⌘O), drop files on the window, or open them from the Finder. Each file is inspected as it arrives: the list on the left says what format it is and how many high-risk items it holds. Word (.docx), Excel (.xlsx) and LibreOffice (.odt, .ods) files are cleaned; Pages and Numbers files are inspected only.

Inspecting any file, and cleaning one file at a time with full verification, are free. A licence adds cleaning several files at once, pseudonymizing with projects, restoring an answer, and signed reports.

The four modes

  • Inspect (⌘1) lists what is hidden, grouped by risk: tracked changes, comments and their authors, hidden sheets, rows and columns, invisible text, cached data, document properties. Show reveals the content itself, in the window only; it never goes into a report.
  • Clean (⌘2) asks the questions that have no safe default, such as what to do with tracked changes, then writes a fresh copy and verifies it.
  • Pseudonymize (⌘3) replaces the values of a project with placeholders such as (PERSON-1), in the file or on the clipboard.
  • Restore (⌘4) puts the real values back into text you paste, such as an AI tool's answer.

The document

The middle shows the text Desk will work on, as it reads it. Original shows the file as Word or Excel would lay it out. In Pseudonymize, every value the project replaces is marked, and Show placeholders shows the text as it will be written.

Cleaning

Start from a preset: Sending to the other side removes everything hidden; Sending to a colleague keeps comments, with their authors anonymised. Either can be changed for each file. Questions with no safe default are always asked, with nothing selected until you choose:

  • Tracked changes: accept all or reject all. Either choice changes what the document says, and Desk says how many words each would keep or drop.
  • Hidden sheets: remove or keep. Formulas that read a removed sheet hold their current values and no longer recalculate; Desk lists which cells before you export.
  • Hidden rows and columns: clear, unhide or keep. Clearing empties the cells; nothing moves.
  • Invisible content: text coloured like its background or too small to read, values hidden by a cell format, headers never shown.
  • Comments: remove, or keep with each author renamed Author 1, Author 2, without dates.
  • Document title: kept only if you say so.

A file with macros is written without them, as the plain format. Unknown parts of a file are removed and reported rather than passed through unexamined.

Verification

After writing a file, Desk opens it again and checks that what you chose to remove is gone and that the file is structurally sound. If a check fails the file is not delivered; you can keep it anyway, which the report records. Verified means what you chose to remove is gone: it does not mean the document is anonymous, and parts a format does not let Desk examine are listed as not examined.

Placeholders and projects

A project holds the values to replace and their placeholders, so (PERSON-1) means the same person in every file pseudonymized with it. Add each value with its spellings separated by |; matching is by whole words, so “Jan” is not found in “January”. The mapping is encrypted on this Mac under a key in its Keychain, and forgetting a project deletes both. Use a project name that says what the files are about, not who is in them: the name is stored unencrypted.

Pseudonymize and Verify writes a file with the placeholders; Copy Text puts the pseudonymized text on the clipboard without writing anything. Pseudonymized is not anonymous: surrounding details can still identify people, and under the GDPR pseudonymized data is still personal data.

Restoring an answer

Paste the answer that refers to placeholders, choose the project, and Restore puts the values back. Placeholders that were not written exactly are listed for you to check, and ones that are not in the project are left as they are. Nothing is written to disk.

Keyboard

  • Open ⌘O · Inspect ⌘1 · Clean ⌘2 · Pseudonymize ⌘3 · Restore ⌘4
  • Restore the pasted text ⌘↩ · Sidebar ⌃⌘S · Workbench ⌃⌘I

Settings

  • General. Which preset new files start from.
  • Text Size is in the View menu.
  • Licence. A Solander Desk or Solander Suite licence, installed from the file you were sent; one Suite file works in both apps. A separate helper process confirms the purchase about once a week and sends nothing about your documents.
  • Updates. Checks can be turned off; licence confirmation is separate and cannot.

Privacy

The app that opens your documents has no network access at all: it is sandboxed without the network entitlement, which you can verify yourself with codesign -d --entitlements - "/Applications/Solander Desk.app". The privacy notice lists exactly what the two helper processes send.

Anything else? Write to hello@quietsignalslab.com, and describe the problem rather than sending the document.
